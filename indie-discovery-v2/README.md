# INDIE DISCOVERY — 2차 디자인 초안

## 실행 방법
`index.html`을 브라우저에서 열어 확인하세요. 인터넷 연결 시 Google Fonts와 Google Maps가 표시됩니다.

## 구성
- HTML: index.html, menu.html, about.html, location.html, contact.html
- CSS: css/common.css + 페이지별 CSS 5개
- 이미지: images 폴더의 SVG 로고, 대표 이미지, 게임 커버 8종

## 반영한 디자인
- PS5 홈 화면에서 영감을 받은 블루 유리 물결·블러·광택 배경 (CSS)
- 실물 게임 케이스의 띠, 측면 두께, 광택 프레임, 입체 기울기
- 메뉴 밑줄 이동, 카드 호버, 배경 흐름, 페이지 등장 모션
- 모바일 CSS 메뉴, 반응형 게임 카드

## 과제 조건 및 한계
- JavaScript 및 script/onclick 미사용
- 공통 CSS와 페이지 CSS 분리, 5개 페이지 동일 메뉴
- 소개 영상은 교체용 자리만 마련되어 있습니다. 실제 영상 파일은 추후 추가해야 합니다.
- 지도는 사용자가 지정한 대구광역시 동구 화랑로 525를 Google Maps iframe으로 표시합니다.
- 장르 필터/정렬은 정적 UI이며 작동하지 않습니다. 문의 폼은 서버가 없어 실제 전송·저장되지 않습니다.
- 게임 커버 8종은 시안용으로 제작한 SVG 일러스트입니다. 실제 게임 이미지로 교체할 수 있습니다.
